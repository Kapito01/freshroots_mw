# Freshroots Brand Design Skill

Use this skill whenever creating or modifying visual elements, page layouts, colour usage, typography, imagery or brand messaging for Freshroots.

## Before designing
1. Read the root CLAUDE.md, docs/BRAND_GUIDELINES.md and docs/DESIGN_SYSTEM.md.
2. Inspect the existing implementation and available approved assets.
3. Keep the existing Freshroots circular F emblem, olive-green identity and warm cream foundation. Do not invent a replacement identity.
4. Distinguish confirmed brand assets from visual placeholders.

## Design execution
- Design a modern African agricultural company, not a generic farm template.
- Use restrained corporate minimalism: clear hierarchy, generous whitespace, confident typography and concise copy.
- Let large, cinematic agricultural photography provide visual character.
- Prioritise authentic Freshroots photographs. Never depict stock/generated images as the client's actual farms, staff, facilities, products or partners.
- Use the palette and type recommendations in the brand/design documents. Check text contrast.
- Avoid excessive cards, gradients, decorative leaves, cartoon tractors, icon clutter, glassmorphism, autoplay media and unnecessary parallax.
- Keep navigation simple and help two audiences find their path: corporate procurement and agricultural supplies.
- Make every interactive element useful, keyboard accessible and responsive.
- Do not copy Oasis Group Africa or another reference site's exact copy, assets, layout or distinctive components. Use only high-level inspiration such as restraint and information hierarchy.

## Content integrity
- Do not invent production capacity, farm acreage, certifications, product stock, prices, partners, clients, awards, delivery coverage or operating locations.
- Keep draft taglines clearly marked as proposals until the client approves one.
- Ask for or document missing assets rather than creating an inaccurate logo.
