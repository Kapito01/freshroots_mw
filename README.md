# Freshroots Malawi

A modern corporate website for Freshroots Malawi, showcasing its integrated agribusiness, rice and maize production, and upcoming agricultural supplies store.

The site is designed around a minimal corporate experience, authentic agricultural storytelling and clear pathways for business enquiries.

## Technology

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint

## Requirements

- Node.js 20.9 or later
- npm (or another compatible package manager)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Important content and imagery note

The first homepage uses temporary Unsplash imagery for layout development. It does not represent Freshroots' actual farms or facilities. Replace it with client-approved Freshroots photography before launch.

The current header monogram is a temporary typographic placeholder. Replace it with the original approved Freshroots logo asset when supplied.

No production statistics, certifications, stock levels, prices, corporate partners or unconfirmed contact information are fabricated. The Agro-Store is presented as an upcoming initiative. E-commerce checkout and online payments are outside the initial release scope.
